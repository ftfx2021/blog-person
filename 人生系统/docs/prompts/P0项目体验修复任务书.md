## 五、实现要求

### 5.1 新建表单校验 + 反馈（R-1）

- `el-form` 绑定 `ref` + `:model` + `:rules` + `label-position="top"`：
  - `title`：`[{ required: true, message: "请输入标题", trigger: "blur" }]`（与服务端 `min(1).max(50)` 一致）
  - 结束不早于开始：自定义 validator（`trigger: "change"`，仅当两者都有值时校验，与服务端 `refine` 一致）
  - `tags`：`max: 20`
- 标题 label 加必填标记；保存按钮 `:loading="saving"`，点击先 `formRef.validate()` 通过再提交
- 失败：`call` 内部已弹 toast，页面 catch 后**保持弹窗打开、输入不丢**；成功：`ElMessage.success("项目已创建")` → 关弹窗 → 刷新

### 5.2 完整编辑弹窗 + 标签修复（R-2，核心）

- 移除 `ElMessageBox.prompt` 仅改标题的做法，**新建/编辑共用同一 `el-dialog` 表单**：
  - 新建：空表单，标题「新建生活项目」
  - 编辑：回填全部字段（`title`/`description`/`goalId`/`startAt`/`endAt`/`tags`），标题「编辑生活项目」；提交走 `projects.update`（**全字段传真实值**，`tags` 必须传回弹窗中的真实标签，**严禁硬编码空数组**）
- **前置（服务端最小改动）**：`src/main/modules/projects/service.ts` 的 `list` 查询**补标签返回**——参考 `goals/service.ts` 的做法，为每个项目聚合 `entity_tag` 的标签名并映射为 `tags` 字段；仅此一处改动，其余查询/更新/删除/状态机逻辑一律不动
- **已完成项目（status=done）**：按服务端"只能修改说明和标签"的约束，编辑弹窗内**禁用**标题/开始时间/结束时间/关联目标字段并显示提示（如「已完成项目只能修改说明和标签」）；仅说明与标签可编辑
- 编辑保存成功 `ElMessage.success("已保存")` → 关弹窗 → 刷新

### 5.3 写操作统一反馈（R-3，贯穿）

- 所有 `async` 处理器（`save`/`edit`/`remove`/`status`）加 `try/catch`：catch 内不重复弹 toast（`call` 已弹），只负责**保持 UI 状态**（弹窗不关、loading 复位、表单不清空）
- 成功路径统一 `ElMessage.success`（创建/编辑/删除/状态变更各自文案）
- `saving` 状态 `finally` 复位

### 5.4 确认框取消捕获（R-4）

- `remove()` 的 `ElMessageBox.confirm` **取消分支 catch**（`try { await confirm } catch { return }`），取消时静默返回；确认后删除成功 `ElMessage.success("已删除")`
- 不再出现取消弹窗时的 UnhandledPromiseRejection（编辑走共用弹窗后，prompt 取消分支自然消除，若有残留一并处理）

### 5.5 状态流转防重复（R-5）

- 状态下拉 `@change` 处理中：对应行下拉 `loading` 或 `disabled`，防止快速连点并发触发
- 可加 `transitioningIds` 集合管理单行状态；完成后清除并刷新

### 5.6 筛选增强（R-6）

- 工具栏增加：
  - **按状态筛选**：`el-select`（active/paused/done，`clearable`，placeholder「全部状态」）
  - **按目标筛选**：`el-select`（选项=已加载 goals，`clearable`，placeholder「按目标」）
- `load()` 组装筛选参数 `{ status, goalId }` 传给 `projects.list`（无值不传）；任一筛选变化 → `load`
- 空结果文案区分"当前筛选下没有项目"与"还没有生活项目"

### 5.7 日期展示 + 到期感知（R-7）

- 列表行展示开始/结束时间（格式化本地日期时间；无值显示"—"或省略）
- 状态为 `active` 且**已过结束时间**（`endAt` 存在且早于当前时间）→ 结束时间红色 + 「已过期」标记（`el-tag type="danger" size="small"`）
- 状态为 `active` 且结束时间在 **7 天内** → 「即将到期」弱提示（可选，样式区分）
- 数据以本地时间比较（时间展示本就是本地化）

### 5.8 列表标签展示（R-8）

- 列表行展示该项目的标签（`el-tag size="small"` 逐个展示，依赖 §5.2 服务端返回的 `tags`）；无标签不显示
- 不改变数据来源与排序逻辑
