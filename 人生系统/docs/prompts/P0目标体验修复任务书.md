## 五、实现要求

### 5.1 新建目标表单（R-1，`GoalsPage.vue`）

- `el-form` 绑定 `ref` + `:model` + `:rules` + `label-position="top"`：
  - `title`：`[{ required: true, message: "请输入标题", trigger: "blur" }]`
  - `metricType === "numeric"` 时动态校验：`startValue`/`targetValue` 必填（`trigger: "change"`）且 **`startValue !== targetValue`**（与服务端 superRefine 一致，自定义 validator）
  - `unit`：`max: 32`
  - `tags`：`max: 20`
- 保存按钮 `:loading="saving"` 点击 → `formRef.validate()` 通过后才 `call`；失败时 `ElMessage` 已在 call 内部弹出，但页面 catch 后**保持弹窗打开**，让用户修正
- 成功：`ElMessage.success("目标已创建")` → 关弹窗 → 跳详情
- 数值型切换时清空/重置起点与目标值默认（避免"切到里程碑又切回"残留旧值）

### 5.2 完整编辑弹窗（R-2，`GoalDetailPage.vue`）

- 替换 `edit()` 的 `ElMessageBox.prompt`（仅标题）为 **`el-dialog` 完整表单**：字段同新建表单（标题/说明/周期/度量方式/单位/起点/目标/截止时间/标签），**初始值回填当前 goal**（含既有 tags，不再硬编码 `[]`）
- `update` 调用时：`tags: form.tags`（**修复标签清空 bug 的关键**）；`confirmRecalculate` 默认 false——若服务端返回 `CONFLICT`（修改起终点需确认重算），弹 `ElMessageBox.confirm` 提示后带 `confirmRecalculate: true` 重发
- 已结束目标（done/abandoned）：按服务端约束只允许编辑说明与标签——弹窗内**禁用**标题/周期/度量字段并提示（或仅提供说明+标签编辑，视实现简便可选）
- 保存成功 `ElMessage.success("已保存")` → 重新加载详情

### 5.3 记录数据 / 添加里程碑（R-3）

- **记录数据**：`record` 表单加 `rules`：数值必填且为有限数、备注 ≤1000；保存失败 catch 后**弹窗不关闭、输入保留**；成功 toast 后关弹窗刷新
- **添加里程碑**：标题 `required` + `max: 100`；同上失败保留输入
- 弹窗表单用 `el-form`（非裸控件）

### 5.4 确认类操作（R-4）

- `finish(status)` / `remove()` / `removeMilestone()`：`ElMessageBox.confirm(...)` 的**取消分支必须 catch**（`try { await confirm } catch { return }` 或 `confirm().catch(() => undefined)`），取消时静默返回
- 确认后执行：成功 `ElMessage.success("目标已完成"/"目标已放弃"/"已删除"/"里程碑已删除")`；失败 catch → toast 已有（call 内部），页面状态不动
- **不再出现**取消弹窗时控制台 UnhandledPromiseRejection

### 5.5 列表搜索 + 状态筛选（R-5）

- 列表页顶栏（或列表上方工具条）加：
  - `el-input` 搜索框（`placeholder="搜索目标标题"`，`clearable`，输入后防抖 300ms 调 `goals.list({ keyword })`）
  - `el-select` 状态筛选（全部/进行中/已完成/已放弃，`clearable`）
- 筛选变化 → `load({ status, keyword })`；`load` 签名改为接收可选筛选参数（默认 `{}` 保持全量）
- 空结果文案区分"无目标"与"筛选无结果"

### 5.6 写操作统一兜底（R-6，贯穿）

- 所有 `async` 事件处理器（save/edit/addRecord/addMilestone/toggle/removeMilestone/finish/remove）加 `try/catch`：`catch` 内**不重复弹 toast**（`call` 已弹），只负责**保持 UI 状态**（弹窗不关、`saving` 复位、表单不清空）
- `saving`/`busy` 状态在 `finally` 复位
- 打开弹窗时重置表单；关闭弹窗不丢已填（取消才丢，失败不丢）
