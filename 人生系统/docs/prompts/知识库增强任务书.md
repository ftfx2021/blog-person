#### 5.1.1 三家在线 OCR（手搓签名，**不引入云 SDK**）

> **⚠️ 实现前必读（用户明确要求）**：以下接口信息为 2026-08-21 联网核实的要点，**仅作方向参考**。动手前**必须先查阅各家官方文档**（链接已附），以官方**最新**文档为准：接口路径、签名算法、公共参数、请求/响应字段、额度与限制。若与本文描述冲突，**以官方文档为准**，并将核实结果记入 `life-system/docs/decisions/`（如 `OCR-接入核实记录.md`）。

| 厂商 | 官方文档入口 | 鉴权 | 接口（核实要点） | 关键点 |
|---|---|---|---|---|
| 百度 | https://cloud.baidu.com/doc/OCR/index.html（通用文字识别-高精度版 accurate_basic 页：`/doc/OCR/s/1k3h7y3db`） | OAuth2 `client_credentials` 换 `access_token`（`https://aip.baidubce.com/oauth/2.0/token`，**有效期 30 天，建议缓存复用**） | `POST https://aip.baidubce.com/rest/2.0/ocr/v1/accurate_basic`（query 带 token；body `application/x-www-form-urlencoded`，`image`=base64+urlencode） | **支持 `pdf_file` 参数直传 PDF**（+`pdf_file_num` 页码，base64+urlencode ≤10M）——若按官方文档确认可用，百度路径**可跳过逐页转图**；图片格式 jpg/jpeg/png/bmp；token 每次请求换取亦可但低效，建议缓存 |

| 阿里 | https://help.aliyun.com/document_detail/294533.html（调用方式）；`/api.aliyun.com/document/ocr-api/2021-07-07/RecognizeGeneral` | RPC 签名（**HMAC-SHA1** + SignatureVersion=1.0） | `POST/GET https://ocr-api.cn-hangzhou.aliyuncs.com/`，Action=`RecognizeGeneral`，**Version=`2021-07-07`**，公共参数含 AccessKeyId/SignatureNonce/Timestamp(UTC ISO8601)/SignatureMethod/SignatureVersion/Format=JSON | 规范化参数（percentEncode + 字典序）→ HMAC-SHA1 签名；body `{ Body: base64 }`；**官方明确暂不支持 PDF 格式**（须逐页转图）；图片 ≤10MB 建议 <1.5M |

- 三家统一输入：单页 PNG base64（百度如确认 pdf_file 直传则走 PDF 参数）；输出：拼接文本（以各家响应字段为准：百度 `words_result[].words`、腾讯 `TextDetections[].DetectedText`、阿里 `Data[].text`——**以官方文档核实为准，未知字段忽略不报错**）
- 错误处理：HTTP 4xx（鉴权/额度）→ 抛可读错误并**标记该厂商不可用**（跳过后续页）；5xx/网络 → 抛错（允许降级下一家）
- 超时 30s/次（沿用 `AbortController` + 重试 1 次）

#### 5.1.2 PDF 转图

- **新增依赖 `@napi-rs/canvas`**（Node 侧 canvas，原生模块）——`npm i @napi-rs/canvas`；**electron-builder 打包需 native rebuild**（任务书附录注明，验收含 `npm run dist:win` 通过或至少 `npm run build` 打包前确认）
- 每页：pdfjs `page.getViewport({ scale: 2 })` → `new canvas.Canvas(w, h)` → `page.render({ canvasContext, viewport })` → `canvas.toBuffer("image/png")`
- 逐页送 OCR，文本按页序 `\n\n` 拼接；扫描件无页码定位

#### 5.1.3 本地 tesseract

- **新增依赖 `tesseract.js`**（WASM）：`createWorker("chi_sim+eng")` → `worker.recognize(imageBuffer)` → `data.text`
- 语言包随应用打包（`node_modules/tesseract.js` 的 lang-data 或显式 corePath/langPath 指向应用资源目录，**不得依赖运行时联网下载**）
- 大 PDF 逐页识别，`worker.terminate()` 释放

### 5.2 ingest 接入 OCR（E-3，`src/main/modules/knowledge/index.ts`）

- `parser/index.ts` 的 `PdfParser`：无文本时抛**特殊错误**（如 `Object.assign(new Error("扫描件需要 OCR"), { code: "OCR_REQUIRED" })`），不再直接当普通解析失败
- `ingest` 解析步骤 catch：`OCR_REQUIRED` → 读 `knowledge.ocr` 设置 → `recognizePdf(storedPath, settings)`：
  - 成功 → OCR 文本作为 rawText 继续规范化/分块（pageLocations=null）
  - 失败/未配置 → 保持既有 `parse_status=failed` + 错误摘要（附"已尝试 OCR：xxx"）
- 设置 `disabled` 时跳过 OCR 直接 failed（提示"扫描件需启用 OCR"）
- 手写/编辑等其它路径不受影响

### 5.3 Chromium 网页抓取（E-4，`knowledge/index.ts`）

`fetchWebpage` 替换为：

```ts
async function fetchWebpageChromium(url: string, timeoutSeconds: number): Promise<string> {
  // 每次抓取独立临时 session，防止目标网页污染默认会话或共享 cookie。
  const session = session.fromPartition(`webpage-fetch-${randomUUID()}`);
  const win = new BrowserWindow({
    show: false,
    webPreferences: { session, sandbox: true, contextIsolation: true, nodeIntegration: false },
  });
  win.webContents.setWindowOpenHandler(() => ({ action: "deny" }));      // 禁止弹窗
  win.webContents.on("will-download", (e) => e.preventDefault());        // 禁止下载
  try {
    await win.loadURL(url, { timeout: timeoutSeconds * 1000 });
    // 等待正文渲染完成：did-finish-load 后 body 可能仍为空，轮询 document.body.innerText 非空（上限 5s）
    const html = await win.webContents.executeJavaScript("document.documentElement.outerHTML");
    if (!html || html.trim().length < 50) throw new Error("页面未渲染出内容");
    return html;
  } catch (error) {
    throw Object.assign(new Error(`网页抓取失败：${message(error)}；若为访问受限，可保存网页后导入文件`), { code: "FILESYSTEM_ERROR" });
  } finally {
    win.destroy();
    await session.clearStorageData().catch(() => undefined);
  }
}
```

- 403/拒绝：Chromium 加载 403 页 → `did-fail-load` 或页面内容为拒绝页 → 走 catch 提示引导手动导入
- 抓取 HTML 仍交既有 `HtmlParser`（去噪 + turndown），管线不变
- 删除原 Node fetch 版 `fetchWebpage`；URL 校验（http/https）保留在调用前
- 串行抓取：`ingest` 本身单条处理，无并发问题

### 5.4 原件操作（E-5）

`documents.ts` 新增：

```ts
openOriginal: async (id: string): Promise<{ opened: boolean }> => {
  const row = await getRow(id);
  if (!row.storedPath) throw notFound("该文档没有原件");
  const path = row.storedPath;
  if (!await exists(path)) throw Object.assign(new Error("原件文件不存在"), { code: "NOT_FOUND" });
  await shell.openPath(path);           // 系统默认程序打开
  return { opened: true };
},
saveOriginal: async (id: string): Promise<{ path: string } | null> => {
  const row = await getRow(id);
  if (!row.storedPath) throw notFound("该文档没有原件");
  const result = await dialog.showSaveDialog({ defaultPath: basename(row.storedPath), filters: [全部文件] });
  if (result.canceled || !result.filePath) return null;      // 用户取消
  await copyFile(row.storedPath, result.filePath);
  return { path: result.filePath };
},
```

- IPC：`knowledge:openOriginal` ← `{ id }`；`knowledge:saveOriginal` ← `{ id }`（均空 schema 之外只用 id）
- Preload：`knowledge.openOriginal(id)` / `knowledge.saveOriginal(id)`
- 详情页：`storedPath` 存在 → 显示「打开原件」「另存原件」按钮（`FolderOpened`/`Download` 图标）；无原件禁用
- 安全：路径仅来自数据库（应用自写目录），不接收渲染层路径

## 六、硬约束（违反即返工）
