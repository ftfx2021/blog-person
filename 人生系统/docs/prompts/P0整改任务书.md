## 四、【P1 建议，一并做】`replaceTags` 标签去重 bug

文件：`src/main/modules/common/database.ts` 的 `replaceTags`。

- 现状问题：用 JS `Set` 去重是**大小写敏感**的，而 `tag.name` 的唯一索引是 `utf8mb4_0900_ai_ci`（**大小写不敏感**）。输入 `['Coding','coding']` 时两轮迭代都会落到同一个 tag、给同一实体插入**两条** `entity_tag`，造成重复标签关联（`entity_tag` 无唯一索引故不报错，属隐性 bug）。
- 修复方向（任选其一，推荐 1）：
  1. 去重时按数据库语义转小写归一，即用 `name.trim().toLowerCase()` 做集合键；且对每个 tag **先查询再决定插入**（命中既有 tag 则复用其 id，不再 INSERT）。
  2. 或对 `entity_tag (entity_type, entity_id, tag_id)` 加唯一索引并在冲突时跳过（需在迁移 SQL 加迁移，改动更大，非必须）。
- 补注释说明：为什么按小写归一（与 `utf8mb4_0900_ai_ci` 唯一索引语义对齐）。
