## 五、实现要求

### 5.1 迁移 008 + Drizzle（P-1）

`migrations/008_task_period.sql`：

```sql
ALTER TABLE task
  ADD COLUMN period VARCHAR(16) NOT NULL DEFAULT 'other' COMMENT '时间范围归类（day/week/month/semester/other）',
  ADD CONSTRAINT ck_task_period CHECK (period IN ('day', 'week', 'month', 'semester', 'other'));
```

- 存量待办默认 `'other'`（无限定），无需数据迁移
- `src/main/infrastructure/db/schema.ts`：`tasks` 表加 `period` 字段（默认 `"other"`）

### 5.2 contracts（P-2）

`src/shared/contracts/entities.ts`：

- 新增 `taskPeriodSchema = z.enum(["day", "week", "month", "semester", "other"])`
- `taskInputSchema` 加 `period: taskPeriodSchema.default("other")`
- `taskUpdateSchema` 自动继承（`taskInputSchema.and(...)`）
- `taskListSchema` 加 `period: taskPeriodSchema.optional()`（按分组筛选，无值=不过滤）

### 5.3 服务层（P-3）

`src/main/modules/tasks/service.ts`（**状态机/事务/筛选既有逻辑不动**）：

- `select` 语句加 `t.period AS period`
- `create`/`update` 的 INSERT/UPDATE 带 period（默认 other）
- `list`：`filter.period` 存在时加 `t.period=?`；返回行含 period
- 其余（status 转换、dateFrom/dateTo、sort、goalId/projectId 筛选）语义不变

### 5.4 UI（P-4）

`src/renderer/features/tasks/TasksPage.vue`：

1. **创建/编辑弹窗加「时间范围」**：`el-select`（选项：日/周/月/学期/其它，值 day/week/month/semester/other，默认其它）
   - 选 `day` → 截止时间默认建议=今天 23:59（可改）；`week` → 本周日 23:59；`month` → 本月最后一天 23:59；`semester`/`other` → 不自动填（保持用户输入或留空）
   - 编辑时回填已存 period；保存提交 `period` 字段
2. **列表分组视图**（主形态，替代当前单列表，或在其上分组）：
   - 按 period 分组，顺序固定：**日 → 周 → 月 → 学期 → 其它**；五组标题（建议：今日 / 本周 / 本月 / 本学期 / 其它无限定）右侧显示该组数量
   - 组内排序沿用现有规则（`due_asc`：有截止的按时间升序在前，无截止的在后；`created_desc` 同理）
   - 已完成待办仍显示在其 period 组内（可折叠/置底，视简洁度；不新增"已完成"独立组）
   - 空组不显示（或显示弱化提示，选择更简洁方案）
3. **筛选联动**：若已有状态/目标/项目筛选，period 分组在筛选结果内生效；顶部可不加 period 下拉（分组本身即分类），如需保留"只看某组"可用组标题点击过滤（可选，不做也不影响验收）
