## Embedding 模型选型确认（2026-08-20）
- 用户提问能否用 qwen3-embedding:0.6b → **确认可用且推荐**（补充进 P1 决策：embedding 默认模型=qwen3-embedding:0.6b）
- 事实（web 核实）：0.6B / 1024 维（MRL 支持降 32-1024）/ 32K 上下文 / 中文"优秀"（MTEB 多语言 64.33）强于 nomic-embed-text / 639MB / CPU 可跑
- 影响：P1-2 建 Milvus `knowledge_chunk_v1` collection 维度按 **1024**（落实"维度随模型配置化"）
- 取舍：追求更高中文召回精度可换 4b（2560 维更准但更吃资源）；0.6b 为默认性价比之选
