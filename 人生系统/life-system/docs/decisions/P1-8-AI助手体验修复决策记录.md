# P1-8 AI 助手体验修复决策记录

本次增量修复保持助手、会话和历史消息语义不变，只扩展推理内容、会话置顶和流式运行时信息。

- 停止操作通过 `AbortSignal` 贯通 provider fetch；外部中止不进入网络重试。
- 思考开关只控制推理增量的展示和持久化，不向各家模型传递不统一的供应商参数。
- 上下文改用约 6000 token 的轻量字符估算，并保留最多 40 条历史兜底。
- 流式断流最多静默重试一次；用户中止和超时不重试。
- Markdown 输出必须经过 MarkdownIt 和 DOMPurify；流式阶段仍使用纯文本。
- 会话置顶、清空、导出和消息操作均通过受控 IPC，由主进程执行数据库与文件访问。
