# P1-2 Milvus 集成决策记录

## 2026-08-21

- 仅引入官方 `@zilliz/milvus2-sdk-node`，通过主进程短生命周期客户端访问固定的 `knowledge_chunk_v1` collection。
- collection 向量维度读取 Embedding Provider 的健康检查结果；已存在 collection 维度不一致时只报告告警，不自动重建。
- Milvus 密码沿用 `app_setting` + Electron `safeStorage`，IPC 只返回掩码；备份 manifest 与向量 JSON 不包含连接凭据。
- Milvus 未配置时备份 manifest 写入 `milvus: null`；已配置但不可用时备份整体失败并清理临时目录。
