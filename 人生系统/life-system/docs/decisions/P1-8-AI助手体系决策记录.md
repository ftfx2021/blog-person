# P1-8 AI 助手体系决策记录

## 2026-08-21

- 助手、会话、历史消息分别持久化到 `ai_assistant`、`ai_session`、`ai_message` 三张表；删除助手或会话使用硬删除和数据库级联。
- 助手本期只开放名称、简介、system prompt；模型配置和知识库字段仅作为未来扩展列，不建立关联和运行逻辑。
- ChatService 的内存 Map 只保存正在生成的流。请求上下文由 system prompt 加数据库最近 20 条消息构成。
- 用户消息发送时立即落库；助手完整回答或停止时的已生成部分落库；LLM 失败时按本轮消息 ID 回滚用户消息。
- 失败回滚只操作 `ai_message`，不查询或注入 `mood_*` 情绪数据，避免私密情绪内容进入助手上下文和 LLM 请求。
- 会话默认名为“新会话”，首条至少 3 个字符的用户消息自动取前 20 个字符命名；用户显式重命名后不再自动覆盖。
