# P0 冲突记录

## document.parse_status 默认值

- FSD 第三部分写为 `ready`，并说明导入时显式写 `pending`。
- 架构文档 4.2 与任务附录 A 均定义数据库默认值为 `pending`。
- 按“字段与 schema 以架构文档为准”的裁决规则，迁移采用 `pending`；P1 导入完成后再显式更新为 `ready`。

## Milvus 备份与恢复

- FSD S01-F06/F07 要求 MySQL 与 Milvus 整体备份恢复。
- 本任务 P0 明确规定 Milvus 仅保存配置并处于“未启用（P1）”降级态，同时 5.7 将 P0 备份范围限定为逻辑库。
- P0 只备份和恢复 MySQL；Milvus 启用后必须补充一致性快照，届时才可宣称包含向量数据。
