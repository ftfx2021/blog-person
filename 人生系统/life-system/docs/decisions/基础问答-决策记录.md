# 基础问答决策记录

## 2026-08-21

- 对话上下文使用主进程内存 `Map<sessionId, ChatMessage[]>`，最多保留 20 条消息；应用重启或页面清空后不恢复历史。
- `ai:chat:start` 和 `ai:chat:stop` 使用既有 `registerHandler` + Zod 校验；流式事件仅通过 preload 固定订阅函数暴露。
- 每个会话同时只允许一个生成任务。停止通过 `AbortController` 标记并终止 AsyncGenerator 读取，结束事件带 `aborted: true`。
- 增量事件使用发起 IPC 的 `event.sender` 定向发送，不广播到其他窗口；事件和日志不包含 API Key。
- 未完成请求发生异常时回滚用户消息，避免失败请求污染下一轮上下文。
