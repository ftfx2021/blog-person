# 数据库设计核对

- 基线：MySQL 8.0+、InnoDB、utf8mb4、UTC `DATETIME(3)`、UUID `CHAR(36)`。
- 表：架构 4.2 的 21 张业务表与 `schema_migrations` 已完整建立。
- 索引：架构列出的 16 个普通索引、业务唯一索引和 `ft_document_content` ngram 全文索引已建立。
- 枚举：全部由命名 CHECK 约束限制；应用层状态机仍负责限制合法流转方向。
- 冗余：只有 `habit.streak`/`last_done_on` 是可从历史回算的读取优化值，每次打卡和撤销后在同一事务重算。
- 测试数据：P0 不向用户空库注入样例，集成测试在独立测试库显式创建固定样本并在结束后清理。
- 已知限制：MySQL DDL 会隐式提交；runner 仅在整份迁移成功后写版本记录。生产升级前须先备份，失败后按未记录版本进行人工审计再续跑。
