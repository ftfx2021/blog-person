# 人生系统 · 治愈男生向 UI 规范

> 依据：`home-healing-male.html` 单文件视觉与交互实现。本文只抽取该页面的设计语言，不代表其它页面的现状。

## 1. 设计定位

### 视觉主张

以“深夜山景中的一盏暖灯”为视觉主张：深靛蓝建立安静、可靠的工作氛围，橙色作为行动焦点，浅灰工作台承接高密度信息；整体克制、温和、有秩序。

### 内容结构

1. 左侧今日脉络：品牌、日期、状态、待办预览、提醒、数据状态。
2. 顶部工作栏：主导航、全局搜索、提醒、设置、个人入口。
3. 今日工作区：日期标题、唯一主行动、今日执行/项目/知识/沉淀/目标/提醒。
4. 底部辅助区：快捷入口、AI 协作、长期资产库。

### 交互主张

- 进入时先看到“今天最重要的一项”，其余内容按信息密度渐进出现。
- 悬停只做轻微抬升或颜色变化，避免打断专注。
- 完成待办、习惯打卡、切换模块均给予短暂 Toast 反馈；通知使用右上抽屉承载。

## 2. 设计令牌

### 色彩

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `canvas` | `#F1F3F6` | 页面背景 |
| `canvas-2` | `#E8ECF2` | 次级背景、浅色层次 |
| `panel` | `#FFFFFF` | 面板、输入框、浮层 |
| `ink` | `#141D33` | 主文字、深色 AI 面板 |
| `muted` | `#5E6B85` | 次级文字、图标 |
| `border` | `#DFE4EC` | 分隔线、描边 |
| `primary` | `#FF9F45` | 主行动、强调、时间线节点 |
| `primary-deep` | `#E0842A` | 主色 hover / pressed |
| `primary-pale` | `#FFF0DE` | 主色浅底、选中背景 |
| `navy` | `#1E2A4A` | 进行中、项目、主要辅助色 |
| `navy-pale` | `#E2E7F2` | navy 浅底 |
| `slate` | `#3A4A6B` | 提醒、数据状态、深色辅助信息 |
| `slate-pale` | `#E6EBF5` | slate 浅底 |

渐变仅用于三类场景：`hero` 深色背景（`#141D33 → #3A4A6B`）、主按钮（`#FF9F45 → #E0842A`）、进度与导航指示（`#1E2A4A → #FF9F45`）。普通内容区域不要新增渐变。

### 字体与排版

- 中文 UI：`Noto Sans SC`，字重 400 / 500 / 700 / 800。
- 情绪化标题：`Source Serif 4`，只用于左侧引导语等少量场景。
- 默认字号 `14px`；辅助信息 `10–12px`；区块标题 `15px / 800`；页面主标题 `26px / 800`；左侧引导语 `22px / 600`。
- 正文行高建议 `1.5–1.7`，标题行高 `1.25–1.4`。不使用负字距。
- 主文字使用 `#141D33`，次文字使用 `#5E6B85`；不要用低于 `#6B7691` 的灰色承载关键状态。

### 间距、尺寸与圆角

- 基础间距单位：`4px`；常用节奏为 `4 / 8 / 12 / 14 / 16 / 18 / 22 / 26 / 30px`。
- 左侧栏宽 `240px`；顶部栏高 `64px`；内容最大宽度 `1280px`。
- 页面内容内边距：水平 `22px`，顶部 `18px`，底部 `26px`。
- 栅格间距 `14px`；面板内边距 `16px`；面板之间不再嵌套面板。
- 面板圆角 `14px`；Hero 圆角 `18px`；按钮/输入框 `10px`；小标签 `6px`；头像 `50%`。
- 交互控件最小点击区域 `36×36px`；复选框视觉尺寸 `20×20px`。

### 阴影与层级

- 普通面板：`0 2px 10px rgba(80,60,40,.05)`。
- 面板 hover：`0 10px 24px rgba(80,60,40,.10)`，同时最多上移 `1px`。
- Hero：`0 14px 32px rgba(30,42,74,.22)`。
- 抽屉：`0 16px 38px rgba(40,30,30,.16)`。
- 阴影用于表达层级，不用于装饰；同一视图不要叠加多种强阴影。

## 3. 布局规范

### 应用壳层

采用“固定左栏 + 弹性主区”的桌面工作台：

- `grid-template-columns: 240px minmax(0, 1fr)`。
- 左栏白色半透明底（约 `0.78` 不透明度），右侧 `1px` 分隔线。
- 顶栏白色半透明底（约 `0.86`），底部 `1px` 分隔线。
- 主区内容居中，最大宽度 `1280px`，不得让信息无限拉宽。

### 首页栅格

- 第一组信息采用 `3` 列等宽栅格，列间距 `14px`。
- 第二组辅助入口同样采用 `3` 列栅格，保持垂直对齐。
- Hero 独占整行，最小高度 `190px`；重点任务浮层最大宽度约 `650px`。
- 插画只作为右下角低干扰装饰，宽度约 `80–106px`，不遮挡文字与操作。

### 响应式基线

当前页面是桌面端基线，保留 `1180px` 最小工作宽度。后续若做响应式，应按以下顺序收缩：隐藏/折叠左栏 → 三列变两列 → 两列变单列；不得直接压缩文字或破坏主行动区域。

## 4. 组件规范

### 导航

- 默认：`14px / 700`，颜色 `muted`，图标与文字间距 `8px`。
- 激活：文字变 `navy`，底部显示 `3px` 高的 `navy → primary` 渐变指示条。
- hover：只改变文字颜色，不增加背景块。
- 主导航顺序固定为：今天、行动、知识、觉察、交付。

### 主按钮

- 高度 `38px`，水平内边距 `16px`，圆角 `10px`，白色文字、橙色渐变底。
- 只用于页面主行动，例如“新建待办”“完成这项”。
- hover 上移 `1px` 并增强阴影；pressed 不再继续上移。
- 同一视图保持一个最主要的主按钮，其余操作使用文字按钮或次级按钮。

### 文字操作与图标按钮

- 文字操作：无背景、无边框，使用 `primary`，字重 `700`；适合“查看全部 →”“进入 →”。
- 图标按钮：`36×36px`、圆角 `10px`、透明底；hover 使用 `primary-pale` 背景和 `primary` 图标。
- 所有仅图标按钮必须有 `aria-label` 或可见 Tooltip；图标库统一 Font Awesome 6。

### 面板

- 白底、`1px border`、`14px` 圆角、轻阴影。
- 标题行使用 `15px / 800`，图标尺寸约 `16px`，间距 `8px`。
- 面板内列表使用 `#E6EAF2` 细分隔线，不使用粗边框。
- 面板 hover 只抬升层级，不改变尺寸，不触发内容重排。

### 待办与习惯

- 待办行是三列：复选框 / 名称 / 截止信息；最小高度 `40px`（紧凑变体 `36px`）。
- 未完成复选框：白底、`2px #CDD5E0` 描边；完成后 `navy` 填充并显示白色勾。
- 完成文字使用低对比灰色并加删除线；不能只依靠颜色表达完成状态。
- 习惯按钮高度 `28px`，未打卡为白底描边，已打卡为 `navy-pale` 浅底。

### 标签与进度

- 标签高度约 `22px`，内边距 `3px 9px`，圆角 `6px`，字号 `11px / 700`。
- 标签语义：主行动用橙色，进行中用 navy，提醒/数据用 slate。
- 进度条高度 `6px`，轨道 `#E6EAF2`，填充使用 `navy → primary`；旁边必须同时展示百分比或可读状态。

### 搜索框

- 高 `36px`、宽 `285px`（窄桌面可缩至约 `208px`），浅灰底、`1px border`、圆角 `10px`。
- focus-within 使用 `primary` 描边和 `3px primary-pale` 外环。
- 保留快捷键提示 `⌘K`；占位文案为“搜索资料、目标、待办”这一类范围明确的提示。

### 通知抽屉与 Toast

- 通知抽屉固定在右上，距顶栏约 `10px`，宽 `340px`，使用面板样式与强阴影。
- 抽屉内用 `2px` 左边色带区分通知，不再添加复杂图标装饰。
- Toast 固定底部居中，深色底、白字、圆角 `10px`，进入/退出使用 `180ms` 淡入和轻微上移。
- 抽屉打开后应支持 Esc 关闭；Toast 使用 `role=status` 与 `aria-live=polite`。

## 5. 动效规范

- 通用过渡：`150–180ms`，使用自然的 ease-out；不做弹跳。
- Hero：山景、月亮、星点和 Lottie 动画只做低速、低对比度循环，不能抢过主行动文字。
- 进入序列：标题 → Hero 重点任务 → 下方栅格，间隔约 `60–90ms`，总时长控制在 `500ms` 内。
- hover：按钮最多 `translateY(-1px)`；面板只增强阴影。
- 支持 `prefers-reduced-motion: reduce`：停用 Lottie、星点和位移动画，仅保留即时状态变化。

## 6. 无障碍与内容规则

- 正文与背景至少达到 WCAG AA 对比度；橙色只用于大字号、图标、边框或按钮底，不单独承载小号正文。
- 所有按钮必须可键盘聚焦，focus 状态使用清晰的 `2–3px` 外环，不得仅依赖 hover。
- 颜色状态必须配合文字、图标、删除线或进度数值表达。
- 装饰性插画、月亮、星点、Lottie 设置 `aria-hidden=true` 或空 alt；信息图像提供替代文本。
- 中文标点统一使用全角；行动文案以动词开头，避免“点击这里”等空泛提示。
