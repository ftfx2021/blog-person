① 阶段一：页面加载

此时侧边栏处于文档流正常位置，position: sticky 已设置但尚未激活。

它就像普通元素一样，占据着自己的空间位置。

🔽 开始向下滚动页面 🔽

观察右侧侧边栏：当它向上滚动到导航栏下方时，会"吸附"在距离顶部70px的位置！

② 阶段二：触发粘性

当侧边栏的顶部触碰到设定位置时（距离视口顶部 70px 处，因为我们设置了 top: 70px），sticky 效果被触发。

此时它会"吸附"在这个位置，看起来像是 position: fixed，但实际上仍然占据原始空间。

这就是 sticky 的魔法：它结合了 relative 和 fixed 的优点！

👀 请看右侧侧边栏，状态指示器会变红并显示"粘性激活中"！

💡 提示：侧边栏会停在导航栏下方，保持合适的间距。

③ 阶段三：保持粘性

继续向下滚动，侧边栏会一直保持在视口的固定位置。

它会跟随页面滚动，但相对于视口的位置保持不变。

这个阶段可以持续很久，直到父容器的边界出现...

🎨 Sticky vs Fixed 区别

Fixed：脱离文档流，不占据空间，永远固定在视口某个位置。

Sticky：保留在文档流中，占据空间，只在特定滚动范围内固定。

Sticky 更智能，它知道自己的"家"在哪里，不会无限制地固定下去。

💡 使用场景

1️⃣ 表格标题行 - 滚动时保持标题可见

2️⃣ 导航栏 - 吸顶导航

3️⃣ 侧边栏目录 - 本例演示的场景

4️⃣ 页面段落标题 - 分组内容时的标题固定

⚙️ 核心CSS代码

.sidebar {
  position: sticky;
  top: 70px; /* 关键参数：距离视口顶部70px */
}

就这么简单！无需 JavaScript，纯 CSS 实现。

⚡ 提示：top值决定了吸附时距离视口顶部的距离。本例设置为70px，正好在导航栏（约50px高）下方留出舒适间距。

🔍 注意事项

1. 父容器不能设置 overflow: hidden/auto（除了 visible）

2. 父容器需要有足够的高度，否则 sticky 无法生效

3. 必须指定 top/bottom/left/right 中的至少一个值

4. 父容器滚动到底部时，sticky 元素会随之停止固定

④ 阶段四：解除粘性

当你滚动到页面底部，侧边栏的底部会触碰到父容器（.sidebar-wrapper）的底部。

此时，sticky 效果自动解除，侧边栏回到正常文档流位置。

它不会继续固定，而是跟随父容器一起滚出视口。

⑤ 阶段五：循环往复

向上滚动回到顶部，整个过程会重新开始。

这就是 sticky 的完整生命周期！

它像一个智能的哨兵，知道何时该固定，何时该放手。

Sticky 定位是现代 Web 开发中非常实用的特性。

它让我们能够创建更好的用户体验，而无需复杂的 JavaScript 代码。
